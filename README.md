# PIXEL PINES — Small Town. Big Mysteries.

Оригинальный англоязычный анимационный сериал для YouTube (дети 7–12 и семьи),
полные эпизоды 6–10 минут. Здесь — вся «студия»: документы сериала и движок,
который собирает эпизод из одного YAML-сценария в готовый MP4 1080p.

## Документы
| Файл | Что внутри |
|---|---|
| `docs/character_bible.md` | Тео, Джун, Дот, пёс Бисквит, Ночной Почтальон: внешность, HEX-цвета, рост, мимика, голоса, характер, отношения |
| `docs/world_bible.md` | город Pixel Pines: география, история, места, легенды, тон |
| `docs/style_guide.md` | визуальный стиль бренда (по референсу), логотип, превью |
| `docs/youtube_research.md` | исследование YouTube: факты с источниками отдельно от гипотез; 5 идей сезона и выбор пилота |
| `episodes/ep101.yaml` | пилот S1E1 «The Letter from Tomorrow» — сценарий + мизансцены |

## Сборка
```bash
pip install --break-system-packages numpy scipy pyyaml skia-python
apt-get install -y ffmpeg libegl1 libgl1          # skia нужен libEGL
python make_episode.py episodes/ep101.yaml               # полный 1080p (~25–40 мин на 4 ядрах)
python make_episode.py episodes/ep101.yaml --preview     # черновик 960×540
python make_episode.py episodes/ep101.yaml --audio-only  # только звук и субтитры
python make_episode.py episodes/ep101.yaml --stills 30 95 300   # контрольные кадры в output/ep101/qc
```
Результат в `output/ep101/`: `pixel_pines_ep101.mp4`, `thumbnail.png`, `subtitles_en.srt`,
`youtube.md` (заголовок, описание с главами, теги, настройки загрузки), `qc/`.

Голоса и звуковые эффекты — ElevenLabs (`ELEVENLABS_API_KEY`). Ответы кэшируются в
`audio/ep101/voice_cache` и `audio/sfx_cache` и лежат в репозитории: повторная сборка
лимит не тратит. Новый/изменённый текст реплики = новый запрос к API.

## Как устроен движок (`studio/`)
* `characters.py` — векторные риги героев: позы рук, походка, мимика (14 выражений),
  моргание, липсинк по таймингам символов ElevenLabs, cel-shading с контровым светом.
* `sets.py` — декорации слоями с параллаксом: Main Street, Maple Row (ночь/утро),
  гараж Дот, лес Whispering Pines, фабрика Лумен снаружи и внутри, холм Lookout.
* `episode.py` — сценарий → таймлайн; «режиссёр» сам выбирает общий/средний/крупный
  план по репликам и эмоциям (явные `cam:` в сценарии важнее).
* `render.py` — камера, глубина резкости на крупных планах, живой свет, тени,
  эффекты, переходы; параллельный рендер в H.264.
* `fx.py`, `inserts.py` — магия «пикселей», конфетти, луч прибора; вставки-детали
  (письмо, конверт, фото, листовка, табличка), логотип, заставка, финальная карточка.
* `voices.py`, `sfx.py`, `music.py`, `mix.py` — голоса, эффекты, процедурная музыка
  (7 тем), сведение с «приседанием» музыки под речь, нормализация −14 LUFS.

## Новый эпизод
Скопируйте `episodes/ep101.yaml`, поменяйте `id`, сцены и реплики. Биты:
`say` (реплика: `text`, `expr`, `pose`, `prop`), `wait`, `act` (`move`, `enter`,
`pose`, `expr`, `prop`, `jump`, `shake`, `vanish`, `appear`), `sfx`, `fx`,
`cam` (`wide`/`medium`/`close`/`insert`), `title`. Выражения и позы — в
`studio/characters.py` (`EXPR`, `POSES`).

## Ограничения (честно)
* Генеративных моделей изображения/видео в окружении нет — анимация рисуется кодом.
  Это стилизованная 2D-анимация инди-уровня, не студийное 3D.
* Ключ ElevenLabs на бесплатном тарифе: нет коммерческой лицензии на голоса и нет
  музыкального API. Для монетизации канала нужен платный план.
