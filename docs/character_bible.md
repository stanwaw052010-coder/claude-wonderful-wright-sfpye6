# PIXEL PINES — Character Bible

*Small Town. Big Mysteries.*

Документ — закон для всех серий. Цвета (HEX), пропорции и силуэты ниже
зашиты в код рига (`studio/characters.py`), поэтому персонажи выглядят
одинаково в каждом кадре и каждом эпизоде. Меняем — сначала здесь, потом в коде.

Единица роста: **Theo = 100**. Голова детей ≈ 1/3 роста (cartoon-пропорции,
крупные глаза — читаемая мимика на телефоне). Контур — тёмный цвет того же
оттенка, не чёрный; свет — мягкая тень снизу-сбоку + тёплый/холодный rim light
по сцене.

## Команда

### THEO BRAMBLE — «тот, кто замечает»
| | |
|---|---|
| Возраст | 11, 6-й класс Pixel Pines Middle School |
| Рост | 100 (≈ 4'8") — эталон |
| Силуэт | шапка каштановых кудрей с одним **вихром-«антенной»** на макушке; длинный жёлтый дождевик до середины бедра |
| Кожа | `#F2C6A0` |
| Волосы | `#7A4A2A`, блик `#A8693E` |
| Глаза | крупные, карие `#5A3A22` |
| Дождевик | горчично-жёлтый `#F2B233`, тень `#C98A1E`, капюшон всегда откинут |
| Джинсы | `#3E5C9A` |
| Кеды | красные `#E2483D`, белая подошва |
| Реквизит | старый **моментальный фотоаппарат «Proof Cam»** на ремне (кремовый `#EDE3C8`); на его снимках иногда видно то, чего не видит глаз |

**Характер.** Любопытный до неприличия, замечает мелочи (часы отстают на 7 минут,
у тени не тот наклон). Говорит быстро, когда взволнован, перескакивает с мысли
на мысль. Верит в загадки, но хочет **доказательств** — поэтому фотоаппарат.

**Сильные стороны:** наблюдательность, упорство, умеет собрать команду.
**Слабые:** нетерпелив, лезет вперёд, не дослушав; боится признать, что ошибся.

**Мимика и жесты:** брови «домиком» от восторга; щурится одним глазом, когда
думает; щёлкает пальцами, когда догадался; поднимает фотоаппарат «как щит».
**Голос:** звонкий, быстрый, американский. Словечки: *«Okay, okay, okay—»*,
*«That's not normal. That's not even a little normal.»*
**Озвучка (ElevenLabs):** Liam, лёгкий сдвиг высоты вверх (моложе).

### JUNE OKAFOR — «та, кто решает»
| | |
|---|---|
| Возраст | 11, одноклассница Тео, младший рейнджер леса |
| Рост | 104 |
| Силуэт | высокий **пучок-«помпон»** из кос, сосново-зелёная повязка; куртка-бомбер |
| Кожа | `#7B4A2E` |
| Волосы | `#2B1B14` |
| Повязка | `#2F8F5B` |
| Куртка | фиолетовая `#7D4CDB`, тень `#5A33A8` |
| Леггинсы | оранжевые `#FF8A3D` |
| Ботинки | коричневые `#6B4226` |
| Реквизит | латунный **компас на шнурке** `#E8C14E`, фонарик, нашивка рейнджера |

**Характер.** Смелая, собранная, первой идёт в тёмный коридор — но только
с планом. Знает каждую тропу, читает карты, считает шаги. Скептик: «Сначала
объяснение, потом магия».

**Сильные стороны:** смелость, логика, лидерство в опасный момент.
**Слабые:** упрямая, трудно просит помощи, раздражается, когда план ломается.

**Мимика и жесты:** одна бровь вверх (скепсис); руки в боки; указывает фонариком;
сверяет компас. **Голос:** уверенный, ровный, с сухим юмором.
Словечки: *«Plan first. Panic later.»*
**Озвучка:** Sarah.

### DOT DELGADO — «та, у кого всё взрывается»
| | |
|---|---|
| Возраст | 10, на класс младше, гений гаража |
| Рост | 90 (самая маленькая) |
| Силуэт | короткое каре с чёлкой, **огромные очки-гогглы на лбу**, белый халат не по размеру с закатанными рукавами |
| Кожа | `#D9A27A`, веснушки `#B97B55` |
| Волосы | `#3A2418` |
| Гогглы | медная оправа `#C77B30`, линзы бирюзовые `#7FE3F0` |
| Халат | `#F4F1EA`, тень `#D5CFC2` |
| Комбинезон | салатовый `#8BC34A` |
| Пояс | инструменты, коричневый `#7A5230` |
| Особая примета | щербинка между передними зубами |

**Характер.** Изобретательница-энтузиаст. Каждое устройство — «Mark» с номером
(*Glitch Sniffer Mk. 7*), потому что Mk. 1–6 «было недоразумение». Изобретения
почти всегда срабатывают **не так**, но в финале именно «неправильная» функция
спасает положение. Обожает слова длиннее себя.

**Сильные стороны:** изобретательность, оптимизм, не боится провала.
**Слабые:** суетлива, не думает о последствиях, обижается, когда над устройствами смеются.

**Мимика и жесты:** опускает гогглы на глаза перед «экспериментом»; трёт ладони;
говорит в ускорении. **Голос:** быстрый, высокий, восторженный.
Словечки: *«Technically, that was a success.»*
**Озвучка:** Laura.

### BISCUIT — пёс с переводчиком
| | |
|---|---|
| Порода | помесь корги и таксы: длинный, низкий, серьёзный |
| Рост | 32 в холке, длина 70 |
| Окрас | сливочный `#F3DDB3`, ирисковое пятно `#C98B4F` на левом глазу и «седло» на спине |
| Уши | **одно стоит, другое висит** — главная примета силуэта |
| Ошейник | бирюзовый `#22C3B5` с круглым динамиком: **светится голубым, когда Бисквит «говорит»** |

**Механика.** Дот собрала ошейник «Woof-to-Words». Он переводит мысли Бисквита…
голосом важного британского рассказчика из документального фильма о природе.
Бисквит уверен, что он благородный исследователь. На деле думает о еде.
Ошейник иногда глючит и выдаёт только «SQUIRREL».

**Характер.** Трусливо-храбрый: сначала прячется, потом совершает подвиг (случайно).
Комментирует события торжественно, как диктор. Верен Тео без оговорок.
**Слабые стороны:** еда, белки, пылесос.
**Голос:** George (тёплый британский рассказчик) — комический контраст с маленькой собакой.
Без слов — синтезированное «вуф» и сопение.

## Загадочный персонаж

### THE NIGHT COURIER — Ночной Почтальон
| | |
|---|---|
| Рост | 190 — почти вдвое выше детей, очень худой |
| Силуэт | длинное тёмно-синее пальто `#1E2A4A` до щиколоток, латунные пуговицы `#D9B25A`, фуражка с козырьком, тёмно-красный шарф `#8E2F3A` |
| Лицо | всегда в тени козырька; видны только **круглые очки, в которых вспыхивает блик** `#FFE9A8` |
| Транспорт | старый велосипед с фонарём; свет фонаря янтарный `#FFB547` |
| Реквизит | кожаная сумка, конверты с марками и **почтовыми штемпелями из будущих дат** |

**Правила персонажа (не нарушать):**
1. Никогда не бегает и не спешит. Появляется и исчезает **на склейке**: был — и нет.
2. Говорит мало, вежливо, загадками. Никогда не угрожает. Не злодей.
3. Каждое письмо, которое он доставляет, запускает приключение серии.
4. Его имени не знает никто. На сумке инициалы «A.L.» — сквозная загадка сезона.
5. Для детской аудитории: присутствие таинственное, но **тёплое**, без хоррора.

**Голос:** Brian — глубокий, спокойный, добрый. Фирменная фраза: *«Right on time.»*

## Взрослые (второй план)
* **Grace Bramble** — мама Тео, держит кафе *The Pinecone Diner* на Main Street.
  Тёплая, вечно занята, верит детям больше, чем говорит. Голос — Matilda.
* **Mr. Hollis** — городской библиотекарь и хранитель архива. Знает историю
  города, говорит длинными предложениями. Голос — Eric.
* **Mayor Pruitt** — мэр, любит ленточки и снос старого ради «прогресса».
  Не злодей — просто не замечает чудес. Голос — Chris.

## Отношения
* **Theo ↔ June** — лучшие друзья с детского сада. Он мечтает, она планирует.
  Спорят каждую серию, но доверяют друг другу полностью.
* **Theo ↔ Dot** — Дот считает Тео «главным испытателем» своих устройств; Тео
  соглашается, потому что её устройства находят то, что не видит камера.
* **June ↔ Dot** — June опекает Дот как младшую сестру и единственная
  читает инструкции к её изобретениям.
* **Biscuit ↔ все** — пёс Тео; June он уважает (у неё сэндвичи), Дот боится
  (она его «модернизирует»).
* **Курьер ↔ команда** — словно знает их давно. Почему — ответ сезона 1.

## Правила узнаваемости (QC в каждой серии)
1. Силуэт каждого героя узнаваем в чёрной заливке: вихор Тео, помпон June,
   гогглы Дот, разные уши Бисквита, рост и фуражка Курьера.
2. Цвет-код: Тео — жёлтый, June — фиолетовый, Дот — белый/салатовый,
   Бисквит — сливочный/бирюза, Курьер — тёмно-синий/янтарь.
3. Магия Pixel Pines всегда выглядит одинаково: **парящие квадратные «пиксели»**
   бирюзового `#6FF2FF` и янтарного `#FFC966` цвета. Никаких других «видов» магии.
