# PIXEL PINES — визуальный стиль бренда

Ориентир — референс-постер владельца канала (ночной городок, тёплый фонарик,
таинственный светящийся проём, логотип справа). Мы берём из него **атмосферу,
палитру, композицию и настроение**, но не копируем персонажей и детали.

## Палитра
| Роль | Цвет | Где |
|---|---|---|
| Ночное небо | `#060b24 → #1d3c86 → #2f5aa8` | все ночные сцены |
| Лунный контровой свет | `#7cc8ff` | rim light персонажей ночью |
| Тёплый ключевой свет | `#ffcf70`, `#ffb050` | окна, фонари, Фонарь Лумен |
| Сумерки | `#1a1a5a → #c0607a → #ffb070` | лес, фабрика, закат |
| Магия «Мерцания» | `#6ff2ff` + `#ffc966` | только квадратные пиксели |
| Логотип | белый `#ffffff`, жёлтый `#ffe45c → #ffb81c`, обводка `#0d0a24` | |
| Слоган | `#bff6ff` + подчёркивание `#6ff2ff` | |

## Свет
Каждая сцена — два источника: **тёплый ключ** (окно, фонарик, лампа) и **холодный
контровой** (луна, светящийся проём). Персонажи подкрашиваются под сцену матрицей
цвета, тени на земле — цветом ночи, не чёрным.

## Персонажи в кадре
Крупные головы (≈1/3 роста), большие глаза с двумя бликами, румянец, тёмный
контур того же оттенка (не чёрный), мягкая тень-серп с дальней от света стороны.

## Композиция превью (thumbnail)
1. Герои слева, крупно, с выражением удивления и тёплым светом снизу.
2. По центру — загадка в светящемся голубом проёме (силуэт Ночного Почтальона).
3. Справа — логотип и название серии в две строки; внизу справа — огни города.
4. Без мелкого текста, читается на телефоне.

## Логотип

слоган SMALL TOWN. BIG MYSTERIES. Шрифт Luckiest Guy (Apache 2.0) + Fredoka (OFL).
