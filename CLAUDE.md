# Pixel Pines — заметки для новой сессии

Англоязычный анимационный сериал для YouTube (дети 7–12 и семьи), эпизоды 6–10 минут.
Пользователь общается по-русски, хочет минимум ручной работы; видео отдавать ссылкой,
с которой можно скачать с телефона (страница-артефакт с capability `downloads`).

## Первым делом
1. `pip install --break-system-packages numpy scipy pyyaml skia-python`
   и `apt-get install -y ffmpeg libegl1 libgl1` (skia нужен libEGL).
2. `python make_episode.py episodes/ep101.yaml` — полный 1080p (~15 мин на 4 ядрах).
   Подробности — README.md.

## Важно
- Голоса и эффекты: ElevenLabs (`ELEVENLABS_API_KEY`), модель eleven_v3 с таймингами.
  Ключ на БЕСПЛАТНОМ тарифе: 10k символов/мес, без коммерческой лицензии, музыкальный
  API недоступен (музыка синтезируется кодом). Кэш в audio/ — не менять тексты реплик зря.
- Визуальный ориентир — постер владельца (ночь, синий + тёплый свет, логотип справа):
  docs/style_guide.md. Персонажи свои (docs/character_bible.md), референс не копировать.
- Детский контент: без хоррора и жестокости; Made for Kids; не публиковать в YouTube
  автоматически.
